The PixelCore family

Built for the 16-bit era.

PixelCore - SNES is an independent Super Nintendo emulator project. The desktop shell, memory foundation, cartridge mapping, and early 65C816 CPU work are underway.

◇

Modern desktop

A native Qt 6 interface designed for Linux desktops.

⌘

65C816 CPU core

A custom processor implementation, expanding through tested instructions and addressing modes.

▤

SNES architecture

Foundations for WRAM, memory mapping, graphics, audio, and cartridge support.

Build PixelCore - SNES

Get the source and compile the current Linux desktop application.

Linux install commands

For Ubuntu, Debian, and Chromebook Linux environments.

sudo apt update
sudo apt install -y git build-essential cmake qt6-base-dev
git clone https://github.com/kaz1071/PixelCore---SNES.git
cd PixelCore---SNES
cmake -S . -B build -DBUILD_TESTING=ON
cmake --build build -j"$(nproc)"
ctest --test-dir build --output-on-failure
./build/pixelcore-snes
